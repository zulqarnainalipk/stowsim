How this works — read me first
  1. Goal: load as many bags as possible into the container (the blue-grey box). The container opens at the front (the opening); bags are pushed in from there, so you fill from the back towards the front.
  2. Pick a bag from the pool (right). Soft bags (blue) must never be buried under hard ones; priority bags (green) belong in the priority container.
  3. Choose where: click in the Top view to put the bag there (it automatically drops onto whatever is below), or use the arrow keys. A green outline means the move is valid, red means blocked (the reason is shown).
  4. Press Place — the real simulator runs the real checks (inside container? clear insertion path? stays stable?). If rejected the episode ends, so aim for valid green moves.
  5. Stuck? Suggest shows the agent's best spots as numbered markers on the top view. Agent step lets the agent move once; Undo takes back your last move.
